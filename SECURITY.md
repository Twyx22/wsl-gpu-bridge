# Security Policy — wsl-gpu-bridge
Owner: `Twyx22` — Repo public — Stdlib only (`wsl_gpu_bridge.py`).

## Supported Versions
| Version | Supported |
| ------- | --------- |
| `main` (latest) | ✅ |
| Tout tag / branche / fork ancien | ❌ |

Seule `main` reçoit les correctifs de sécurité.

## Scope
- In scope : `wsl_gpu_bridge.py` sur `main`.
- Out of scope : forks, snippets, dépendances système, WSL / pilotes GPU.

## Reporting
N'ouvrez pas d'issue publique. Utilisez exclusivement :
1. **GitHub Private Vulnerability Reporting** (`Security > Report a vulnerability`) — voie préférée.
2. **GitHub Security Advisories** privé.

Pas d'email en clair. Ne publiez ni PoC ni exploit avant correctif.

Inclure : version/commit `main`, OS/WSL/Python, repro minimale stdlib, impact.

## Disclosure
- Accusé de réception : 7 jours.
- Correctif / advisory : 90 jours max.
- Divulgation coordonnée ; CVE via GitHub si applicable.
